# Platform Engineering Architect Course

Course material and final assignment for the [Platform Engineering Architect](https://university.platformengineering.org/) course at Platform Engineering University.

## Repository Structure

### [`capstone-project/`](capstone-project/README.md)

Contains the **deliverables of the final assignment** for the Platform Engineering Architect course. This includes all the Kubernetes manifests, configurations, and supporting code that make up the completed capstone submission.

### `setup/`

Contains the **course setup material**: infrastructure configuration (Kind cluster setup, Terraform definitions) needed to provision the local environment used throughout the course.

### [`workshop/`](workshop/README.md)

Contains the **course material leading up to the final assignment**: workshop exercises, READMEs, and example configurations covering topics such as Gatekeeper policies, Falco rules, security operations, and the teams management application.
